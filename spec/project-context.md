# Project Context

> High-level context for the project: the problem being solved, who it's for, what's in scope, and what constraints apply.

## 1. Vision

Replicate the Kenya Java User Group (Kenya JUG) website as a modern, responsive web application. The application serves as a digital hub for Kenya JUG community members to learn about the organization, find event information, access resources, and engage with the Java developer community in Kenya. The website showcases the organization's mission, past and upcoming events, team members, and provides easy access to community resources and social media channels.

## 2. Users

- **Community Members:** Java developers and enthusiasts in Kenya who visit the site to learn about Kenya JUG, find upcoming events, and connect with the community.
- **Event Attendees:** Developers interested in registering for or learning more about Kenya JUG meetups and conferences.
- **Administrators:** Kenya JUG team members who manage event information, speaker details, and website content (backend admin functionality, not public-facing).

## 3. Constraints

- The application must be fully self-contained — no external API integrations or third-party data sources (events, speakers, and content are managed within the application).
- The UI and UX must closely replicate the Kenya JUG website at https://kenyajug.org/?v=2.
- The site must be responsive and work on mobile, tablet, and desktop devices.
- Public pages are accessible to anonymous users; admin features require authentication.
