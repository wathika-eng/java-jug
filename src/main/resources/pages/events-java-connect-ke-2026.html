Java Connect KE 2026

About the day

About 200 developers, talks on modern Java, Jakarta and AI, a Spring AI workshop and a panel on modern Java in the age of AI.

The second Java Connect KE was our biggest day yet. Venkat Subramaniam took the room through records and pattern matching, functional programming done right, and concurrency. Ivar Grimstad of the Eclipse Foundation showed where Jakarta EE meets AI, Elvis Parsaloi made the case for modular monoliths, Ian Dancan and Newton Wamiti ran a hands-on Spring AI workshop, and a panel of speakers and community members discussed modern Java in the age of AI.
