About Kenya JUG

A community that shows up.

Kenya Java User Group (Kenya JUG) is a community-driven organisation that brings together Java developers, enthusiasts, students and industry professionals across Kenya. We help developers at every level learn, connect and contribute to the global Java community through meetups, workshops, conferences and university chapters.

Mission

To grow Kenya’s Java ecosystem through knowledge sharing, technical events, mentorship and industry collaboration.

Vision

Every Java developer and student in Kenya has a community to learn from, and a voice in the global Java ecosystem.

What we stand for

Our values

  1. 01

    Open to everyone

    Students, beginners and senior engineers are equally welcome, and membership is free.

  2. 02

    Learn by sharing

    Everyone has something to teach. We give first-time speakers a stage and help them prepare.

  3. 03

    Hands on

    We learn by building: workshops, live demos and code you can run yourself.

  4. 04

    Local roots, global reach

    We bring global Java voices to Kenya, and help Kenyan developers contribute to the wider Java community.
